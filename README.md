# Loam Bundle

A growing collection of browser-playable synthesizers. Each one is a single
self-contained HTML file — no build step, no install, just open it.

## Synths

- [**Loam Eight Sub**](loam-eight-sub/) — 8-voice subtractive synth with
  oscillator, filter, ADSR envelope, delay, and reverb. Play it with your
  computer keyboard (`A`–`;`) or the on-screen keys.

More to come.
